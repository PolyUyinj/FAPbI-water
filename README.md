# FAPbI/water 
## Downstream-dataset
Downstream dataset for fine-tuning DPA-2 model. Please use `cat train_* > train-total.xyz` to get complete dataset.
## Lammps-input
Lammps input files for MD simulations in article. Please use `cat *-430K-traj_* > *-430K-traj-complete.mp4` to watch the compelte video of MD trajectories.
## MLP
Compressed machine learning potential file. 
## Testing-dataset
Testing dataset for RMSE testing.
## VASP-INCAR
VASP INCAR for labeling configurations.
